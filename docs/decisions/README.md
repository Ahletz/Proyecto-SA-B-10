# Decisiones de Arquitectura (ADR)

Este documento registra las decisiones arquitectónicas importantes del proyecto Bank USAC, su justificación y las alternativas consideradas.

## Formato de cada decisión

Cada decisión debe incluir:
- **Decisión:** qué se decidió
- **Contexto:** por qué era necesario decidir esto
- **Alternativas consideradas:** qué otras opciones se evaluaron
- **Justificación:** por qué se eligió esta opción
- **Consecuencias:** qué implica esta decisión para el resto del sistema
